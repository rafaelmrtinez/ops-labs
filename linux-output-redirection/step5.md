## Level 4 – Combining Output Streams

**Difficulty:** Moderate

**Situation:**

We're preparing a troubleshooting report. We need successful command output and error messages recorded together for further investigation.

**Task:**

Execute a command that lists `/etc` and `/directory-that-does-not-exist`, redirecting both STDOUT and STDERR into `system-report.log`.

**Expected Result:**

Both successful results and error messages should appear in the same file.
