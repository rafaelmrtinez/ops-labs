# Level 5 – Troubleshooting and Log Management

**Difficulty: Hard**

**Situation:**

We're performing a diagnostic check on a Linux system. We need to capture successful command output and errors in one log file while preserving previously recorded information.

**Tasks:**

1. Create a diagnostic log named `diagnostics.log` containing the following message:

   `Diagnostic session started`

2. Execute `ls -l /etc` and append its output to `diagnostics.log`.

3. Execute `ls -l /directory-that-does-not-exist` and append both its normal output and error messages to `diagnostics.log`.

4. Display the contents of `diagnostics.log` to verify the results.

**Expected Result:**

Your `diagnostics.log` should contain:

- The original `Diagnostic session started` message.
- The successful directory listing from `/etc`.
- The error message generated by accessing the nonexistent directory.

All information must be preserved in the same file.
